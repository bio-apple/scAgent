# knowledge/best_practices

Per-step SOP summaries distilled from Heumos et al. 2023, sc-best-practices.org, and the 10x Genomics analysis guide. Informed defaults, not dogma.

Fused into the RAG index as collection `best_practices`. Agents boost the SOP files that match the current analysis route. Pull the live book with `python -m scagent update-kb` (writes `knowledge/upstream/`, gitignored).
